Last week, Wiz disclosed a major security exposure involving Moltbook, an AI agent social network. A misconfigured database exposed 1.5 million API keys, each one capable of fully impersonating an agent on the platform. Anyone with a leaked key could post content, send messages, or modify data as that agent.
